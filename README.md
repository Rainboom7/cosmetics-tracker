# Косметичка

Android-приложение для учёта своей косметики и списка желаемого.

- **Коллекция** с фото: что есть, что открыто, сколько осталось, когда истекает срок после
  вскрытия (PAO). Напоминания за 30 дней до конца срока.
- **Желаемое**: «Хочу сильно», цена, ссылка; кнопка «Куплено» переносит средство в коллекцию.
- **Каталог**: поиск по открытой базе [Open Beauty Facts](https://world.openbeautyfacts.org)
  с фотографиями продуктов.
- **Добавление**: сканер штрихкода, поиск по фото упаковки (распознавание прямо на телефоне,
  ML Kit), ручной ввод с обязательным фото. Если похожее уже есть, приложение подскажет.
- Резервная копия коллекции в JSON-файл.

## Сборка

Нужны JDK 17+ и Android SDK (Android Studio подойдёт).

```bash
./gradlew :app:assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew -p core test              # тесты логики (без Android SDK)
./gradlew :app:testDebugUnitTest    # тесты Android-части (Robolectric)
```

Готовый debug-APK собирает CI на каждый push (артефакт `app-debug-apk` во вкладке Actions).

Минимальная версия Android: 8.0 (API 26).
